# 🌐 Laboratório de Arquitetura em Microsoft Azure

Este repositório foi desenvolvido como parte do laboratório prático para apresentar os conceitos fundamentais sobre **construção de arquiteturas na plataforma Microsoft Azure**.

## 🎯 Objetivo do Projeto

- Apresentar os principais componentes arquiteturais da Azure.

- Demonstrar como projetar e visualizar arquiteturas em nuvem.

- Servir como repositório de apoio com resumos, comandos e dicas úteis.



## 📌 O Que Você Vai Encontrar Aqui

- ✅ Dicas sobre boas práticas de arquitetura em nuvem.

- 🧱 Resumo dos principais serviços Azure usados em arquiteturas.

- 🛠️ Exemplos de ferramentas como o **Azure Architecture Center** e o **Azure Diagrams**.

- 🖼️ Diagramas representativos de soluções.


## 📚 Recursos Úteis

- [Microsoft Azure Architecture Center](https://learn.microsoft.com/en-us/azure/architecture/)

- [Azure Well-Architected Framework](https://learn.microsoft.com/en-us/azure/architecture/framework/)

- [Azure Diagrams](https://learn.microsoft.com/en-us/azure/architecture/icons/)
