#  Modelos de Arquitetura em Microsoft Azure

Este arquivo apresenta exemplos e padrões arquiteturais típicos utilizados em soluções com Azure.

## 📌 Exemplo 1: Aplicação Web com Banco de Dados

**Componentes:**

- Azure App Service

- Azure SQL Database

- Azure Application Gateway

- Azure Key Vault

- Azure Monitor

**Benefícios:**

- Escalabilidade automática

- Conexões seguras

- Alta disponibilidade

## 📌 Exemplo 2: Arquitetura com Contêineres

**Componentes:**

- Azure Kubernetes Service (AKS)

- Azure Container Registry

- Azure Load Balancer

- Azure Log Analytics

## 📌 Exemplo 3: IoT + Análise de Dados

**Componentes:**

- Azure IoT Hub

- Azure Stream Analytics

- Azure Data Lake / Synapse

- Power BI

**Aplicações:**

- Monitoramento em tempo real

- Análise preditiva

- Relatórios interativos


## 📷 Dica

Para criar diagramas claros, utilize a ferramenta [Azure Diagrams](https://learn.microsoft.com/en-us/azure/architecture/icons/) com ícones oficiais da Microsoft.
